# rasa-bot-assignment

 ----------Steps to Test and Use the Voice-Assisted Bot----------

Download zip file for executable.
https://drive.google.com/file/d/1YeEaMNA3H3bi2T6zoUG4RUQXTkze6ryW/view?usp=sharing

>> Start the Bot
Double-click the "DoCE Assignment " executable to launch the Rasa bot server and the React frontend.

>> Note: It may take 3–5 minutes to start, depending on your system and the size of the Rasa models. This executable runs without requiring Python or additional dependencies.

>> Open the App
Once the application window appears, it will display the next steps.
Copy the provided URL and open it in Google Chrome to use the voice assistant features. Voice Assistant feature will not work in other browsers.

>> Test the Bot
Interact with the bot using voice or text and enjoy the experience.
